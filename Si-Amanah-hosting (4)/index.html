              Pusat Rekap & Laporan

              Ringkasan seluruh program Adiwiyata dalam satu tempat. Cetak per bagian atau sekaligus dalam satu dokumen.

              Galeri Adiwiyata

              Dokumentasi kegiatan, bukti setoran, kondisi tanaman, penjualan, dan inventaris. Ketuk ♥ untuk menyukai dan menyimpan ke favorit.

              Pusat Pengaturan

              Kelola profil madrasah, pengumuman, akun pengguna, serta penyimpanan dan cadangan data.

              Identitas & Penanda Tangan

              Data ini tampil pada kop dan tanda tangan setiap laporan PDF.

              Petugas / Kader Bank Sampah

              Bisa lebih dari satu orang. Nama pertama tampil sebagai penanda tangan laporan bank sampah. Ketuk ★ untuk menjadikan penanda tangan.

                Kontak Operator Adiwiyata

                Pengumuman / Informasi Terkini

                Isi hingga 3 pesan. Pesan tampil bergantian setiap 5 detik di Beranda seluruh akun, tepat di bawah ucapan salam dan tanggal. Kosongkan kolom untuk tidak memakai pesan tersebut.

                Tambah Akun

                Admin — semua fitur termasuk akun, pengaturan, pengumuman, galeri, dan proses penarikan tabungan.

                Guru — kelola kegiatan, bank sampah, penjualan, inventaris, laporan.

                Kader Adiwiyata — input kegiatan, kondisi tanaman, inventaris, transaksi bank sampah, dan penjualan hasil.

                Non-kader — melihat informasi, saldo sendiri, dan mengajukan pengambilan tabungan.

                Nama lengkap akun siswa dipakai untuk menampilkan setoran miliknya, jadi tulis sama persis dengan nama penyetor.

                  Penyimpanan & Sinkronisasi

                  Data disimpan otomatis setiap 30 detik di perangkat ini dan, bila aplikasi dipasang di hosting, juga di server.

                  Cadangan Data

                  Unduh cadangan secara berkala dan simpan di tempat aman. Restore menggabungkan data cadangan dengan data saat ini.

                  Zona berbahaya

                  Menghapus seluruh data dan akun secara permanen. Server tetap menyimpan satu cadangan terakhir.
